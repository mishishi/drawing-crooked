# 画传歪了 — 设计规格书

> 基于 2026-05-08 头脑风暴讨论

---

## 1. 概念与愿景

**「画传歪了」** 是一个多人联机派对整活游戏，核心乐趣在于：每人画一笔，越传越歪，笑点来自于传递过程中的脑洞误解。

游戏视觉上拥抱「不完美的美感」——所有元素都是歪歪扭扭的手绘涂鸦风，像真实的素描本上画的。歪斜不是缺陷，而是设计语言。

**记忆点**：歪斜卡片系统 + 蜡笔质感 + sketchbook 纸纹背景

---

## 2. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Vue3 | Composition API |
| 画布 | HTML5 Canvas | 原生 API |
| 实时通信 | Socket.io-client | WebSocket |
| 后端 | Node.js + Express | — |
| 房间/实时 | Socket.io | — |
| 部署 | Nginx 反向代理 | 后期转云 |

### 项目结构：Monorepo
```
doodle-loop/
├── frontend/          # Vue3 项目
├── backend/           # Node.js + Express + Socket.io
├── docs/              # 设计文档
└── sentences.json     # 题库（共享）
```

## 3. 设计语言

### 配色
```css
--bg-paper: #FFF8F0;        /* 暖白，素描纸色 */
--color-primary: #2D3436;   /* 深炭灰，有温度 */
--color-accent-red: #FF6B6B;   /* 珊瑚红 */
--color-accent-purple: #6C5CE7; /* 薰衣草紫 */
--color-accent-yellow: #FDCB6E; /* 柠檬黄 */
--color-line: #2D3436;      /* 手绘线条 */
```

### 字体
- **标题/装饰**：ZCOOL KuaiLe（站酷快乐体）— 手写中文感
- **正文**：Noto Sans SC — 圆润、友好

### 视觉风格
- 手绘涂鸦质感边框（非直角）
- sketchbook 纸纹背景
- 蜡笔/马克笔质感颜色
- 所有卡片轻微倾斜，打破网格严肃感

### 动效
- 元素轻微 wobble 摇晃
- 按钮点击弹性 bounce
- 画布入场卷轴展开
- 揭晓时刻戏剧性翻页

## 4. MVP 最小闭环功能

### Phase 1 — 基础设施
- [ ] Monorepo 项目搭建（frontend + backend）
- [ ] Socket.io 连接验证

### Phase 2 — 房间系统
- [ ] 创建房间（生成 6 位房间号）
- [ ] 加入房间（房间号输入）
- [ ] 等待室（玩家列表 + 准备状态）
- [ ] 房主开始游戏

### Phase 3 — 核心玩法
- [ ] 画布：画笔/橡皮/粗细/颜色
- [ ] 画布同步（每笔实时推送）
- [ ] 句子派发（每人随机一句）
- [ ] 传递逻辑（顺时针传递一圈）
- [ ] 30 秒倒计时 + 超时提交

## 5. 页面结构

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 标题 + 创建房间 + 加入房间 |
| 等待室 | `/room/:roomId` | 房间号 + 玩家列表 + 准备 |
| 画画页 | `/room/:roomId/play` | 画布 + 工具栏 + 倒计时 |
| 传递页 | `/room/:roomId/waiting` | 等待下一轮动画 |
| 揭晓页 | `/room/:roomId/reveal` | 所有画作 + 原句展示 |

### 工具栏布局
- **PC**：顶部工具栏
- **Mobile**：底部工具栏（拇指友好）
- 响应式适配

## 6. Socket.io 事件（最小闭环）

### 客户端 → 服务端
| 事件 | payload | 说明 |
|------|---------|------|
| `create-room` | `{ playerName }` | 创建房间 |
| `join-room` | `{ roomId, playerName }` | 加入房间 |
| `player-ready` | `{}` | 玩家准备 |
| `start-game` | `{}` | 房主开始 |
| `draw-stroke` | `{ imageData }` | 单笔数据 |
| `submit-drawing` | `{}` | 提交画作 |

### 服务端 → 客户端
| 事件 | payload | 说明 |
|------|---------|------|
| `room-joined` | `{ room, playerId }` | 加入成功 |
| `player-joined` | `{ player }` | 新玩家加入 |
| `player-left` | `{ playerId }` | 玩家离开 |
| `your-sentence` | `{ sentence }` | 收到句子 |
| `new-round` | `{ round, currentPlayer, drawing }` | 新一轮 |
| `drawing-update` | `{ imageData }` | 画布更新 |
| `game-ended` | `{ results }` | 游戏结束 |

## 8. 验收标准

1. 4-8 人可加入同一房间
2. 每人收到不同句子且互不可见
3. 30 秒倒计时内可画画，超时自动提交
4. 画作可传递给下一位玩家
5. 一圈传递后展示所有画作和原句
6. PC 和手机浏览器均可正常使用
7. 无文字/字母出现（检测机制后期加）
